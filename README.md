# Симулятор орбитальной сварки

Кликабельный концепт интерфейса тач-панели аппарата орбитальной сварки. Экран 1024×600.

Открыть: https://timofeevaekaterinan-rgb.github.io/csm-welding-simulator/

- `simulator/v2.html` – основной вариант: программы по секторам, ручной режим, функции, полный цикл сварки, режим ожидания.
- `simulator/index.html` – вариант 1.
- `simulator/standby-anim.html` – анимация режима ожидания.
